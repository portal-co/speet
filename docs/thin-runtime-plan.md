# Thin Runtime Plan

On-demand **native-to-native** recompilation: load a host binary, translate through speet → WASM → wasm-blitz (host JIT), link with a tunneled host API shim, and spawn a child process.

This is the complement to [container-plan.md](container-plan.md), which produces a single **pure WASM** megabinary with **no host JIT**.

---

## Two main strategies

| Strategy | Guest at run | Host JIT? | Compile when | Host boundary |
|---|---|---|---|---|
| **Container megabinary** | Pure WASM blob in vkernel | No | Build time | `osctx::OS` / vkernel |
| **Thin runtime** | Native linked executable | Yes (wasm-blitz SysV v1) | On demand | Pluggable `HostApi` (default: tunnel) |

Planned thin-runtime enhancements: [future/host-jit.md](future/host-jit.md), [future/direct-linking.md](future/direct-linking.md). Shared future capability: [future/ptrace-emulation.md](future/ptrace-emulation.md) (indexed in [future-features.md](future-features.md)).

---

## Pipeline

```
host binary / corpus object
  → binary_io::load_auto (Phase 1+) or corpus .text extract
  → speet-recompile::frontend (guest machine code → WASM)
  → speet-recompile::drive (WASM → relocatable .o via wasm-blitz)
  → LLVM clang + lld link (guest.o + speet-rt + HostApi shim + tunnel dylibs)
  → spawn child process
```

**Crates:**

| Crate | Role |
|---|---|
| `speet-host-api` | `HostApi` trait, `TunneledHostApi` default, `FilteredHostApi`, registry |
| `speet-rt` | C memory bootstrap (`__wasm_mem`, `__wasm_memory_grow`) |
| `speet-runtime` | Driver, `LlvmToolchain`, link, cache, spawn |
| `speet-recompile` | Frontend + backend pipeline library |
| `tunnel` | libc/libSystem symbol allowlist and link flags |

## HostApi

Guest code reaches the host through two mechanisms:

1. **WASM imports** (`env__exit`, `env__write`, …) — C shim stubs generated by `speet_rt::generate_shim`.
2. **Ambient labels** (`__ambient_write`, …) — `tunnel` alias pairs at link time.

These two are meant to be symmetric alternatives for the *same* redirect, not a fixed split by symbol: `PltRedirect::WasmImport`/`PltRedirect::Ambient` (`speet-host-api`) let a `HostApi` backend resolve a given guest symbol to either mechanism, decided by whether that backend actually has a live host image to alias against (`HostApi::supports_ambient_linking`) — a compile-time construction input, never a runtime auto-discovery. See [docs/guides/thin-runtime-genericity.md](guides/thin-runtime-genericity.md) and [docs/future/abi-spec-redirects.md](future/abi-spec-redirects.md) for how a resolved redirect eventually gets a real translation stub instead of a bare passthrough.

`TunneledHostApi` (default) resolves against `LinuxLibcTunnel` / `MacLibSystemTunnel`. Unknown symbols fail closed at link time.

```rust
pub trait HostApi: Send + Sync {
    fn import_manifest(&self) -> ImportManifest;
    fn resolve_ambient(&self, guest_name: &str) -> Option<TunnelResolution>;
    fn link_recipe(&self) -> LinkRecipe;
    fn syscall(&mut self, nr: u64, args: &[u64]) -> i64 { -1 }
}
```

Backends: `TunneledHostApi` (Phase 0), `FilteredHostApi` (Phase 2), future `OsctxHostApi` bridge to vkernel.

## LLVM toolchain

The link step uses **LLVM only** — `clang` + `lld` (`-fuse-ld=lld`). No Xcode or Apple system toolchain dependency.

Detection order: `CLANG` / `LLD` env vars → Homebrew LLVM paths → `PATH`. Tests skip gracefully when LLVM is absent.

---

## Phase 0 corpus

Guests live in `test-data/thin-runtime-corpus/`. Pre-built `.elf` / `.macho` blobs are committed; `compile_corpus.sh` rebuilds them with `llvm-mc` + `llvm-objcopy`.

Primary syscall guest: RV64 Linux `exit(42)` (`rv64-linux/exit_42`). Full roundtrip tests target **x86_64/ELF** and **aarch64/Mach-O** output (matching `speet-e2e` `NATIVE_TARGETS`).

## Threat model (Phase 0)

Same-user, same-platform, explicit invocation. Tunnel allowlist limits ambient libc; recompiled code is native — trust boundary is whoever invoked the runtime.

---

## Integration points

- **Container plan:** shares `osctx`, manifest syscall schema, `ExternalTargets`, future ptrace layer. Does **not** share vkernel No-JIT enforcement (thin output is native code).
- **Plugin API:** `TargetPlugin` syscall tables can feed recompilation; `PluginTransport` pattern mirrors `HostApi` pluggability.
